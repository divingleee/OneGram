# OneGram 1克


## 概述

一个 macOS 菜单栏系统监控工具，界面简洁，占用资源极小，对于电脑来说其占用的资源就如 “1克“ 的重量。

## 功能特性

- 菜单栏常驻：展示 CPU / GPU / 内存 / 网络上行 / 网络下行；，列间用 `｜` 分隔，紧凑省宽度。
- 无窗口、无子进程：不 fork 任何子进程（不解析 `netstat`），全部通过 Darwin / Mach / IOKit 系统接口直接读取。

## 资源占用实测

以下数据在 Release 构建、5 个指标全开、默认 2 秒刷新、数值持续变化的条件下实测（180 秒窗口）：

| 指标 | 实测               | 换算到一天                                             |
| --- |------------------|---------------------------------------------------|
| CPU 平均占用 | 0.32%（按单个 CPU 核心计） | 一天累计约 4.6 分钟 |
| 内存 | 约 21MB（物理内存） | --                                                |
| 耗电 | 平均功率约 6 毫瓦   | 一天约 0.00015 度电（6mw*24=0.144wh=0.000144度电）     |
| 安装包大小 | 500k             | --                                                |

CPU 占用换算

- 0.32% 是什么意思：把「一个 CPU 核心」满负荷算作 100%，OneGram 平均只用到其中的 0.32%。
- 一天用多少：24 小时累计约 4.6 分钟处于工作状态，其余约 1435 分钟（99.7% 的时间）CPU 都在休息。
- 按整机算更小：现在 Mac 一般有 8-12 个核心，换算到所有核心平均只有约 0.03%~0.04%，基本感觉不到。

电耗换算（1 度电 = 1 千瓦时 = 1000Wh）

- 电脑总电量：MacBook 电池容量约 50-70Wh，也就是 0.05-0.07 度电；
- OneGram 一天用 0.144Wh 电：约 0.00015 度电，只相当于满电电池的 0.25%。
- 直观感受：一天 24 小时一直开着它，大约 19 年才用掉 1 度电。


为什么能做到这么小：

- 2 秒（可控）才醒来一次：每次采样只是几个微秒级的系统调用，随后立刻回到 `Task.sleep`；对比常见的 100ms 轮询监控工具，唤醒频率低 20\~50 倍。
- 不勾选就不采集：隐藏的指标完全不会触发对应系统调用；全部关闭时采样循环直接退出，CPU 占用归零。
- 数据不变就不重画：菜单栏标签是一张自绘图片，数值没变化时缓存直接命中，跳过全部测量、布局、绘制。
- 零子进程：不用 `netstat` 之类的命令行工具，全靠系统接口，不产生任何额外进程。
